title: Server directory
description: The list of conformant servers (directory)
---

The list of conformant servers is served as static JSON. An app only needs to read this one file.

- List: [`/servers.json`](/servers.json)
- Format: an array `servers` (each with the server URL, conformance level and suite version). The exact shape will be fixed before the directory is published.

> **No servers are listed yet.** The directory's public location and application contact are undecided. See [Status and open items](/en/status/).
